# Requirements

## 1. Create Project Data Structure

Separate project information from the page component.

Create:

```
data/projects.ts
```

The project data should contain fields similar to:

```ts
{
  title: string,

  description: string,

  technologies: string[],

  category: string,

  github?: string,

  demo?: string
}
```

Do not hard-code project information directly inside the page component.

---

# 2. Create ProjectCard Component

Create a reusable component:

```
components/ProjectCard.tsx
```

The component should display:

* Project title
* Short description
* Category
* Technology tags
* GitHub link if available
* Demo link if available
