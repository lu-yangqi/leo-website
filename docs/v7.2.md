Version 7.1.0

---

# 1. Task

Implement Version 7.2 of the Leo Personal Website.

Version 7.1 already provides the SEO and discoverability foundation:

- Central production site configuration
- `metadataBase`
- Canonical URLs
- Dynamic `sitemap.xml`
- `robots.txt`
- Open Graph text metadata
- Twitter / social text metadata
- Article metadata derived from Markdown frontmatter

Version 7.2 should add a simple, consistent visual identity for browser tabs, device icons, and shared links.

The goal is NOT to redesign the website UI.

The goal is to make the deployed website feel like a complete public site when:

- opened in a browser tab
- bookmarked
- added to a mobile home screen
- shared in messaging apps
- shared in social platforms
- previewed through Open Graph metadata

Keep this version small and focused.
