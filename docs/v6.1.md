# Leo Personal Website - v6.1

## Task

Implement Version 6.1 of the personal website.

The current project baseline is **Version 6.0**.

Version 6.0 already provides:

* Complete responsive About page
* Centralized typed profile data in `data/profile.ts`
* Education
* Research Interests
* Technical Interests
* Skills
* Currently Learning
* Learning Background
* Selected Work
* Shared ContactLinks component
* Projects page
* Markdown Blog
* Blog article detail routes
* Markdown rendering
* Syntax highlighting
* Blog tags
* Back to Blog navigation

The goal of Version 6.1 is to transform the homepage from a relatively simple personal introduction into a useful content-driven personal homepage.

The homepage should summarize the most important parts of the existing website.

It should help visitors quickly understand:

1. Who Leo is
2. What he is interested in
3. What he has built
4. What he is currently learning
5. What he has recently written
6. Where to go for more information

Do not duplicate entire pages.

Do not perform the planned major visual redesign yet.
