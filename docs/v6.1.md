# Leo Personal Website - v6.1

## Task

Implement Version 6.1 of the personal website.

The goal of this version is to transform the homepage from a simple introduction page into a useful personal homepage that summarizes the most important parts of the website.

Version 6.0 should already provide a real About page with structured personal profile content.

Version 6.1 should integrate selected content from:

* About / personal profile
* Research interests
* Projects
* Current learning
* Blog / Notes

into the homepage.

Do not duplicate entire pages.

The homepage should act as a concise entry point that helps visitors quickly understand:

1. Who Leo is
2. What he is interested in
3. What he has built
4. What he is currently learning
5. What he has recently written
6. Where to go for more information
