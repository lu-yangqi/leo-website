# Leo Personal Website - v7.0

## Task

Implement Version 7.0 of the personal website.

Version 7.0 is the **first public deployment milestone**.

The current project baseline is:

```text
Version 6.2.0
```

The primary goal is:

```text
Local Website
      ↓
GitHub Repository
      ↓
Vercel
      ↓
Public Production URL
```

Version 7.0 should make the existing website safely deployable and ready for its first public production release.

Keep the scope intentionally small.

Do NOT combine deployment with SEO, visual redesign, animation, custom domains, analytics, or major architecture work.

# Existing Bilingual Architecture

Version 6.2 currently uses:

```text
English as the static/default language
+
Client-side persistent language preference
```

The website already supports:

```text
EN | 中文
```

through the shared Navbar.

Language selection persists using browser storage.

Core content supports bilingual presentation.

Blog articles retain their original writing language.

Do not redesign this architecture during Version 7.0.

---

# Important Known Limitation

The current bilingual architecture intentionally uses shared routes.

Static HTML is currently English-first.

A persisted Chinese preference may be restored after hydration.

Dedicated routes such as:

```text
/en/about
/zh/about
```

do not currently exist.

The website also does not yet provide:

```text
hreflang
locale-specific static HTML
locale-specific canonical URLs
```

This is NOT a Version 7.0 problem.

Do not implement locale routing in this version.

These issues belong to a later:

```text
Version 7.1 — SEO & Discoverability
```
