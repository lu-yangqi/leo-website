# V8.1.3 --- Responsive Hero Cinematic Adaptation

## Task

Extend the completed V8.1 Hero identity transition to support more
real-world viewport conditions.

The goal is not to redesign the animation, but to make the existing
portrait → signature experience work consistently across desktop
windows, compact layouts, and mobile devices.

------------------------------------------------------------------------

## Main Goal

Preserve the approved identity sequence:

``` text
Portrait
    ↓
Center Focus
    ↓
Portrait Fade Out
    ↓
Leo Signature Reveal
    ↓
Homepage Content
```

The animation story should remain the same on every device.

------------------------------------------------------------------------

## Approved Visual Decisions

Do not change:

-   Portrait center position
-   `finalPortraitScale = 0.58`
-   Portrait fade concept
-   Portrait/signature handoff
-   Leo signature reveal
-   Wide desktop composition

The current desktop visual direction is approved.

------------------------------------------------------------------------

## Responsive Hero Modes

Replace the current binary behavior:

``` text
Cinematic
    or
Static
```

with responsive modes:

``` text
Wide Cinematic
        ↓
Compact Cinematic
        ↓
Mobile Cinematic
        ↓
Static Fallback
```

------------------------------------------------------------------------

## Wide Desktop

Keep the current experience:

``` text
Text + Portrait

↓

Center transition

↓

Signature
```

Requirements:

-   Scroll-linked animation
-   Existing timeline
-   Existing controller
-   Existing signature reveal

------------------------------------------------------------------------

## Compact Desktop / Windowed Browser

Problem:

Some desktop browsers do not meet the current cinematic threshold
because of reduced height.

Example:

``` text
1200 × 650
```

Requirements:

-   Keep cinematic behavior
-   Keep the same identity sequence
-   Adjust physical scroll distance if necessary
-   Do not disable the Hero animation only because of viewport height

------------------------------------------------------------------------

## Mobile

Mobile uses a different layout, but the same story.

Layout:

``` text
Text

↓

Portrait

↓

Center transition

↓

Signature
```

Requirements:

-   Keep shared Hero state logic
-   Keep scroll-linked behavior
-   Do not create a separate Hero implementation
-   Do not replace with an unrelated autoplay animation

------------------------------------------------------------------------

## Viewport Handling

Improve mode detection.

Consider:

-   Width
-   Height
-   Orientation
-   `prefers-reduced-motion`

Use viewport-safe sizing where appropriate:

-   `svh`
-   `dvh`

Ensure:

-   Resize does not leave stale transforms
-   Mode changes reset correctly
-   Reverse scrolling remains correct
