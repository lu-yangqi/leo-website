# Current Problem

The Navbar works correctly, but it does not show which page is currently active.

For example:

When visiting:

```text
/projects
```

the navigation currently looks similar to:

```text
Home    Projects    Blog    About
```

There is no clear indication that the user is currently on the Projects page.

This should be improved.

---

# Requirements

## 1. Add Active Navigation State

The Navbar should detect the current route.

For example:

```text
Home    [Projects]    Blog    About
```

when the current URL is:

```text
/projects
```

The active link should be visually different from normal navigation links.

Possible differences include:

* Different text weight
* Different text color
* Subtle background
* Underline or indicator

Keep the design minimal and professional.

Do not use excessive visual effects.

---

## 2. Use Next.js Routing APIs

Use the appropriate modern Next.js App Router approach to determine the current route.

Prefer:

```text
usePathname()
```

if appropriate.

Keep the implementation simple.

Because route detection requires client-side navigation information, only convert the component to a Client Component if necessary.

Do not convert unrelated components into Client Components.

---

## 3. Improve Navigation Interaction

Refine the Navbar interaction states.

Navigation links should have clear but subtle:

* Default state
* Hover state
* Active state
* Keyboard focus state

The active state and hover state should be distinguishable.

Accessibility should not be reduced.

---

## 4. Preserve Responsive Navigation

The existing navigation already works on smaller screens.

Do not introduce horizontal overflow.

Test at approximately:

```text
390px
```

viewport width.

The navigation should remain readable and usable.

Do not add a complex mobile menu unless it is actually necessary.
