# Leo Personal Website - v7.1

## Task

Implement Version 7.1 of the personal website.

Version 7.1 is the first SEO and search-engine discoverability foundation for the publicly deployed website.

Current production website:

https://leo-website-lilac.vercel.app

Current baseline:

Version 7.0.0

Version 7.0 already provides:

- Public Vercel deployment
- GitHub main → Vercel automatic deployment
- Home
- About
- Projects
- Blog
- Static Blog article routes
- Responsive desktop / mobile layouts
- English / Chinese UI switching
- Markdown rendering
- Syntax highlighting
- Production-tested routes and 404 behavior

Version 7.1 should improve how search engines and link-preview systems understand the website.

Keep this version intentionally small.

Do NOT redesign the application architecture.

# Requirement 5 — Canonical URLs

Add canonical URLs for public pages.

Examples:

```text

https://leo-website-lilac.vercel.app/projects

```

Blog article canonical URLs should be generated dynamically:

```text

```

Use the Next.js Metadata API.

Do not manually write `<link rel="canonical">` throughout components unless the framework architecture genuinely requires it.

# Requirement 6 — Bilingual SEO Decision

The current language system uses shared routes.

Example:

```text
/about
```

can visually display English or Chinese depending on the user's stored language preference.

There are currently no separate:

```text
/en/about
/zh/about
```

routes.

Therefore Version 7.1 should NOT add fake `hreflang` entries.

Do not claim that English and Chinese are separate indexable pages when they share the same URL.

For Version 7.1:

```text
English static HTML
=
primary search-engine / canonical representation
```

Chinese remains:

```text
user-selectable client presentation
```

This is intentional.

Do not perform a routing rewrite solely for multilingual SEO.
