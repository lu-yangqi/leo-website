# Leo Personal Website - v5.0

## Task

Implement Version 5.0 of the personal website.

The goal is to create the basic foundation of a Markdown-based blog system.

Do not build a complete blog platform.
Only implement the basic architecture for displaying blog posts.

---

## Current Project Status

Completed:

- Next.js project
- TypeScript
- Tailwind CSS
- Homepage
- Navbar
- Footer
- Multi-page routing
- Project showcase framework

Current routes:

/
 /projects
 /blog
 /about


The `/blog` page is currently a placeholder.

---

## Main Goal

Create this data flow:

Markdown files

↓

Blog data loader

↓

Blog page

↓

BlogCard components


---

## Requirements

### 1. Create Blog Content Directory

Create:

content/blog/


---

### 2. Create Initial Blog Files

Create:

content/blog/

- personal-website-codex.md
- ctf-learning.md
- cs231n-learning.md
- machine-learning-andrew-ng.md


These files should only contain:

- title
- description
- date
- category

Do not write long articles.


---

### 3. Create Blog Data Loader

Create:

lib/blog.ts


Responsibilities:

- Read markdown files
- Extract metadata
- Return blog list


Keep file loading logic separate from React components.


---

### 4. Create BlogCard Component

Create:

components/BlogCard.tsx


Display:

- title
- description
- category
- date


---

### 5. Update Blog Page

Modify:

app/blog/page.tsx


Requirements:

- Load blog data from lib/blog.ts
- Render BlogCard components
- Remove placeholder content
