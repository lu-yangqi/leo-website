# V8.1 --- Hero Cinematic Motion Foundation

## Task

Upgrade the homepage Hero experience with a cinematic transition
foundation while keeping personal signature and portrait assets
replaceable.

The goal is to create the interaction framework first, then integrate
the final Leo signature and portrait in a later iteration.

## Main Goal

Create a smooth identity transition:

Portrait → Center Focus → Signature Placeholder → Content Transition

The Hero should feel:

-   Personal
-   Smooth
-   Elegant
-   Technical
-   Maintainable

## Core Concept

Version 8.1 focuses only on the motion system.

The initial implementation should provide the complete animation
structure without requiring final personal assets.

### Hero Sequence

``` text
01. Portrait Introduction

Large visual placeholder appears.

↓

02. Center Lock

The visual element smoothly scales down and moves to the center.

↓

03. Signature Reveal

A placeholder signature area appears.

↓

04. Transition

The Hero scene transitions naturally into homepage content.
```

## Design Requirements

### Portrait System

Implement:

-   Large Hero visual area
-   Replaceable portrait component
-   Smooth scale transition
-   Center alignment state

The final portrait asset will be integrated later.

### Signature System

Implement:

-   Signature placeholder component
-   Reserved animation timeline
-   SVG-compatible container

The final Leo signature will be added in a future iteration.

The signature system should support:

-   SVG path animation
-   Stroke drawing effect
-   Dark/light background usage

## Motion Requirements

The Hero animation should support:

-   Scroll-linked progress
-   Smooth transformations
-   Controlled timing
-   GPU-friendly animation

Preferred approach:

-   Sticky Hero scene
-   CSS variables
-   Transform and opacity transitions
-   requestAnimationFrame only when necessary

## Technical Constraints

Preserve:

-   Existing routes
-   Existing SEO metadata
-   Existing bilingual architecture
-   Existing Markdown blog system
-   Existing profile and project data

Avoid:

-   Architecture rewrite
-   Heavy animation dependencies
-   Unnecessary WebGL implementation

## Performance Requirements

The implementation should:

-   Maintain smooth scrolling
-   Respect `prefers-reduced-motion`
-   Avoid continuous React state updates during scrolling
-   Keep server-rendered content available
-   Avoid layout shifts
