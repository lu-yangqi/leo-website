# V8.1.2 --- Hero Portrait Integration

## Task

Integrate the final portrait asset into the existing V8.1 cinematic Hero
sequence.

The goal is to replace the temporary portrait placeholder while
preserving the completed Hero motion system and Leo signature
integration.

## Main Goal

Complete the identity transition:

``` text
Portrait
    ↓
Center Focus
    ↓
Leo Signature Reveal
    ↓
Homepage Content
```

The portrait should become the first visual identity element of the
homepage and work naturally with the existing scroll-linked animation.

## Requirements

## Portrait Asset Integration

Replace:

``` text
PortraitPlaceholder
```

with the final portrait image.

Recommended location:

``` text
public/
└── images/
    └── hero/
        └── leo-portrait.jpg
```

Alternative:

``` text
public/
└── portraits/
    └── leo-portrait.jpg
```

Keep the asset isolated and easy to replace.

## Portrait Requirements

The portrait should:

-   Match the existing Hero composition
-   Support responsive cropping
-   Maintain stable dimensions
-   Avoid layout shifts
-   Work with Next.js image optimization

Recommended format:

-   JPG for photography
-   WebP if optimized later

Recommended aspect ratio:

-   Portrait orientation
-   Approximately 3:4

## Motion Integration

Preserve the existing V8.1 Hero controller.

Target sequence:

``` text
01 Portrait Introduction

Large portrait presentation

↓

02 Center Lock

Portrait smoothly scales and moves to center

↓

03 Signature Reveal

Portrait remains part of the identity scene

↓

04 Transition

Homepage content becomes active
```

Do not rewrite the Hero architecture.

## Technical Constraints

Preserve:

-   Existing routes
-   Existing SEO system
-   Existing bilingual architecture
-   Existing Markdown blog system
-   Existing Hero timing controller

Avoid:

-   Architecture rewrite
-   Heavy image dependencies
-   Unnecessary animation libraries

## Performance Requirements

The implementation should:

-   Use optimized image loading
-   Avoid layout shifts
-   Respect reduced motion
-   Keep static fallback behavior
-   Preserve smooth scrolling
